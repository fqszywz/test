- 列表标签
 - 作用：布局内容排列整齐的区域
 - 列表分类：无序列表、有序列表、定义列表

  - 无序列表：工作中经常使用的列表
    - 作用：布局排列整齐的不需要规定顺序的区域
    - 标签：ul嵌套li,ul是无序列表标签，li是列表项标签
    <ul>
     <li>列表项1</li>
     <li>列表项2</li>
     <li>列表项3</li>
     <li>...</li>
    </ul>
    - 注意事项：
      - 列表项标签ul嵌套li，li标签不能单独使用
      - ul标签里面只能包裹li标签，不能包裹其他标签
      - li标签里面可以包裹任何内容

  - 有序列表：
    - 作用：布局排列整齐的需要规定顺序的区域
    - 标签：ol嵌套li,ol是有序列表标签，li是列表项标签
    <ol>
     <li>列表项1</li>
     <li>列表项2</li>
     <li>列表项3</li>
     <li>...</li>
    </ol>
    - 注意事项：
      - 列表项标签ol嵌套li，li标签不能单独使用
      - ol标签里面只能包裹li标签，不能包裹其他标签
      - li标签里面可以包裹任何内容

  - 定义列表：一般用作页面底部，帮助中心的区域
    - 作用：定义列表，一般用于页面底部，帮助中心区域
    - 标签：dl嵌套dt和dd,dl是定义列表的标签，dt是定义列表的标题，dd是定义列表的描述、详情
    <dl>
     <dt>定义列表的标题</dt>
     <dd>定义列表的描述、详情</dd>
    </dl>
    - 注意事项：
      - 列表项标签dl只能包含dt和dd
      - dt和dd标签里面可以包含任何内容
