 - CSS定义：层叠样式表，是一种样式表语言，用来描述HTML文档的呈现（美化内容）
 - CSS引入方式：
   - 内部样式表：在HTML文档的head标签中定义,学习使用
     - CSS代码写在style标签中
   - 外部样式表：在HTML文档的head标签中定义，并引入外部样式表，开发使用
     - CSS代码写在单独的CSS文件中（.css）
     - 在HTML使用link标签引入外部样式表
       <link rel="stylesheet" href="css/style.css">
   - 行内样式：配合JavaScript使用
     - CSS写在标签的style属性中
       <p style="color: red;font-size:20px;">这是div标签</p>

  - 选择器  作用：查找标签，设置样式
    - 基础选择器：
      - 标签选择器：选择所有指定标签，例如p标签，div标签，span标签等等
        - 使用标签名作为选择器-->选中同名标签设置相同的样式
      - 类选择器：选择所有指定类，例如.class1，.class2，....，.class6
        - 作用：查找标签，差异化设置标签的显示效果
        - 步骤：
          - 定义类选择器：.类名
          - 使用类选择器：标签添加class="类名"
        - 注意：
          - 类名自定义，不要用纯数字或中文，尽量用英文命名
          - 一个类选择器可以供多个标签使用
          - 一个标签可以使用多个类名，类名之间用空格隔开
        - 开发习惯：类名见名知意，多个单词可以用 - 连接，例如: news-hd

      - id选择器：选择所有指定id，例如#id1，#id2，#id3，.....,#id10
        - 作用：查找标签，差异化设置标签的显示效果
        - 场景：id选择器一般配合JavaScript使用，很少用来设置CSS样式
        - 步骤：
          - 定义id选择器：#id名
          - 使用id选择器：标签添加id="id名"
        - 规则：
          - 同一个id选择器在一个页面只能使用一次

      - 通配选择器：选择所有标签，例如*
        - 作用：查找页面所有标签，设置相同样式
        - 通配符选择器：*，不需要调用，浏览器自动查找页面所有标签，设置相同样式

  - 画盒子
    - 目标：使用合适的选择器画盒子
    - 新属性：
      - width：设置盒子宽度
      - height：设置盒子高度
      - border：设置盒子边框
      - padding：设置盒子内边距
      - margin：设置盒子外边距
      - background：设置盒子背景
      - display：设置盒子显示方式
      - float：设置盒子浮动
      - clear：设置盒子清除浮动
      - position：设置盒子定位
      - top：设置盒子上外边距
      - left：设置盒子左外边距
      - right：设置盒子右外边距
      - bottom：设置盒子下外边距
      - z-index：设置盒子堆叠顺序
      - opacity：设置盒子透明度
      - cursor：设置鼠标样式
      - font-size：设置字体大小
      - font-family：设置字体
      - font-weight：设置字体粗细
